# lc0-keras Package

A clean, isolated Python package providing custom Keras layers for Leela Chess Zero models.

## Package Structure

```
src/python/
├── pyproject.toml          # Package configuration (hatchling build system)
├── README.md               # Package documentation
├── .gitignore             # Python/build artifacts
└── lc0keras/              # Main package
    ├── __init__.py        # Package initialization and exports
    └── layers.py          # Custom Keras layer implementations
```

## Package Details

- **Package Name**: `lc0-keras` (PyPI name, installable via pip/uv)
- **Import Name**: `lc0keras` (Python import name)
- **Version**: 0.1.0
- **License**: GPL-3.0-or-later (same as LCZero project)

## Installation Methods

### 1. From GitHub via uv (Recommended)

```bash
uv add git+https://github.com/LeelaChessZero/lc0#subdirectory=src/python
```

### 2. From GitHub via pip

```bash
pip install git+https://github.com/LeelaChessZero/lc0#subdirectory=src/python
```

### 3. Local Development (Editable Install)

```bash
cd /path/to/lc0/src/python
pip install -e .
# or
uv pip install -e .
```

### 4. Build and Install from Source

```bash
cd /path/to/lc0/src/python
pip install build
python -m build
pip install dist/lc0_keras-0.1.0-py3-none-any.whl
```

## Usage

### Basic Usage

```python
import lc0keras  # Registers all custom layers
import keras

model = keras.models.load_model('network.keras', safe_mode=True)
```

### Importing Specific Layers

```python
from lc0keras import MatMul, DynamicTile, SliceLayer
import keras

# All layers are already registered with Keras
model = keras.models.load_model('network.keras', safe_mode=True)
```

## Exported Layers

The package exports 8 custom Keras layers:

1. **`MatMul`** - Batch matrix multiplication
2. **`Gather`** - Index-based gathering (wraps `tf.gather`)
3. **`DynamicTile`** - Batch-aware tiling with dynamic shapes
4. **`StaticRepeat`** - Static repetition along an axis
5. **`SliceLayer`** - Tensor slicing with start/size parameters
6. **`FlattenBatchSpatial`** - `(batch, 64, C)` → `(batch*64, C)`
7. **`UnflattenBatchSpatial`** - `(batch*64, C)` → `(batch, 64, C)`
8. **`DynamicReshape`** - Dynamic reshape with `-1` inference

All layers are:
- ✅ Fully serializable (`get_config()` / `from_config()`)
- ✅ Registered with `@keras.saving.register_keras_serializable()`
- ✅ Support dynamic batch sizes
- ✅ Compatible with `safe_mode=True`

## Dependencies

- `tensorflow >= 2.13.0`
- `keras >= 3.0.0`
- `numpy >= 1.23.0`

## Python Version Support

- Python 3.8+
- Tested on Python 3.9, 3.10, 3.11, 3.12, 3.13

## Integration with LCZero

The `lc0` binary's `leela2keras` command automatically generates Python code that imports this package:

```python
# Generated by lc0 leela2keras
import lc0keras
from lc0keras import (
    MatMul, Gather, DynamicTile, StaticRepeat, SliceLayer,
    FlattenBatchSpatial, UnflattenBatchSpatial, DynamicReshape
)
```

### Package Isolation

This package is completely isolated from the rest of the LCZero codebase:
- No dependencies on C++ code
- No dependencies on other Python files in the repo
- Can be installed and used independently
- Only requires standard ML packages (TensorFlow, Keras, NumPy)

## Why a Separate Package?

1. **Clean Separation**: ML model loading code separate from chess engine
2. **Easy Distribution**: Users can `pip install` or `uv add` from GitHub
3. **Version Management**: Independent versioning from main lc0 binary
4. **Reusability**: Other projects can use LCZero models without lc0 binary
5. **Standard Python Practices**: Follows Python packaging conventions
